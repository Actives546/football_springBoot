## 二、必选技术栈与中间件（仅做基础集成，启动连通即可）

### 核心微服务组件

- 服务网关：Spring Cloud Gateway
- 服务远程调用：OpenFeign

- 通用工具：Lombok、Hutool、commons-lang3

- 分布式缓存：Redis
- 消息中间件：RabbitMQ
- 搜索引擎：Elasticsearch

## 三、严格限定项目模块（仅保留 4 个模块，严禁多生成、少生成）

- **父工程：sports-cloud**
  职责：全局依赖管理、统一版本锁定、dependencyManagement 管理所有依赖，不编写任何业务代码和配置文件（除pom.xml外）。
- **公共模块：sports-common**
  职责：全局通用配置、工具类、基础异常处理、OpenFeign 通用配置、公共实体基类，打包为 jar 供其他模块依赖，不包含业务逻辑。
- **网关服务：sports-gateway**
  职责：微服务统一入口、Nacos 注册、路由转发配置、全局跨域配置，无任何业务代码，仅保留网关核心配置和启动类。
- **用户微服务：sports-user**
  职责：唯一业务微服务，集成 MySQL、Redis、RabbitMQ、ES 全部基础配置，提供最简测试接口，无复杂业务逻辑，仅用于验证服务连通性。
